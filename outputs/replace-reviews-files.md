# Files To Replace Reviews

## Main Review Data

Replace or edit customer reviews here:

- `lib/data/reviews.ts`

This file controls:

- homepage featured reviews
- reviews page cards
- review schema markup

## Review-Related Page Usage

The review data is rendered into:

- `app/page.tsx`
- `app/reviews/page.tsx`
- `lib/schema.ts`

You usually only need to edit `lib/data/reviews.ts`.
